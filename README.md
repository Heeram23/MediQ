# MediQ – Hospital Token & Queue Management System

## Project Overview

MediQ is a web-based Token and Queue Management System designed for hospital Outpatient Departments (OPDs). It allows patients to generate tokens online, select doctors or departments, and track their queue position and estimated waiting time.

The system helps hospitals reduce waiting times, minimize overcrowding, and improve patient flow through digital queue management.

## Objectives

- Reduce long waiting lines in hospitals.
- Provide online token generation.
- Allow patients to track their queue position.
- Improve hospital queue management.
- Help doctors and receptionists manage patient turns.
- Reduce manual work and human errors.

## Key Features

- User Registration and Login
- Online Token Generation
- Doctor and Department Selection
- Live Queue Tracking
- Estimated Waiting Time
- Walk-in Token Management
- Doctor Dashboard
- Receptionist Dashboard
- Admin Dashboard
- SMS and Email Notifications
- Patient and Queue Reports
