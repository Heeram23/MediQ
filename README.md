# MediQ
MediQ is a web-based Token and Queue Management System designed for hospital Outpatient Departments (OPDs). It allows patients to generate tokens online, select doctors or departments, and track their live queue position. The system helps hospitals reduce waiting times, minimize overcrowding, and improve patient flow through digital queue management. It also provides dedicated features for doctors, receptionists, and administrators.

Project Overview
MediQ aims to digitize the traditional hospital token and queue management process. Patients can book tokens remotely and monitor their waiting status, while hospital staff can manage queues, patient turns, departments, and schedules efficiently. The goal is to make hospital visits more organized, convenient, and time-saving.
